# Task 1: How to set up Obsidian

You should already have Obsidian downloaded and installed. Open the app and click the *Create* button to create a new vault. Give it a name and click *Create* again. To create a new note, click on the *New note* button. Give the note a title and start writing. 

## Formatting
Obsidian notes are stored as Markdown files, which have a specific way of formatting text. Surrounding text in different amounts of asterisks (\*) results in your text being italic, bold, or both, as shown in the table below.

| Symbol | Format                |
| ------ | --------------------- |
| \*     |             *Italic*  |
| \*\*   |             **Bold**  |
| \*\*\* | ***Bold and italic*** |

Additionally, you can create headings by using the hashtag symbol \#, with more hashtags resulting in a smaller heading.

# Heading 1: \# \{text}
## Heading 2: \#\# \{text}
### Heading 3: \#\#\# \{text}

Obsidian also uses MathJax to interpret LaTeX equations, which allows for writing complex math equations. Surrounding an equation in dollar sign symbols \$ creates a math equation, which will render inline with other text unless you use two dollar sign symbols instead. Inline: $2x+3$ (2x+3)

$$x^2$$ 

(x^2)
