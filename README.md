# Overview of Obsidian documentation

This documentation will guide you with detailed step-by-step instructions on using Obsidian. This guide is intended for first year CST students. We will cover 4 important tasks.

1. Set up Obsidian and link between notes and folders
2. Write math equations and format text
3. Create and organize a knowledge base
4. Use and add plugins

## How we collaborated

We decided to split up the work and assign eachother an equal amount of tasks and other pages. We used Discord as our main communication tool while working on this documentation. We also used GitHub for version control.

## Creating the guide

We created this guide using our knowledge of Obsidian gained by using it for CST for a year. We used our knowledge to guide readers on the most important and useful things to set up first.

## Using MkDocs

We used Material for MkDocs and customized the scheme to be purple similar to Obsidian.

## Improving readability

We used GIFs and screenshots to visually show what steps to take. We also used admonitions to highlight important information.

## Conclusion

We hope this document helps you use Obsidian more efficiently and improve your organizational skills. Thank you for reading.
